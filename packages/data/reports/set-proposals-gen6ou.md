# Gen 6 OU — proposed set changes

These come after the build fixes. Gen 6's data was already the cleanest of the four gens. Most of what's left is labels on Calm Mind and Nasty Plot tanks, and a few near-duplicates.

## Drop

| Species    | Set                                         | Why                                                                                             |
| ---------- | ------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| Cloyster   | Shell Smash "The Janitor" (Hydro Pump), 19% | Hydro Pump from 4 Sp. Atk EVs on a Jolly nature; otherwise the same as the main Shell Smash set |
| Talonflame | Swords Dance (specially defensive)          | Same four moves as the Bulky Swords Dance set                                                   |
| Togekiss   | Nasty Plot (physically defensive)           | Nearly the same as the offensive Nasty Plot set                                                 |

## Keep: flags that are actually fine

- **Hand-added sets that are real Gen 6 sets:** Weavile Swords Dance, Ferrothorn Stealth Rock, Tornadus-T Life Orb, Skarmory Defog, Chansey and Blissey Wish, Magnezone Specs, Amoonguss specially defensive, Azelf Expert Belt, Quagsire Curse, Politoed Scarf, Nidoking lead, Mandibuzz, Feraligatr and Hawlucha Choice Band.
- **"No STAB" that comes from an ability:** Pinsir and Altaria use Return / Hyper Voice turned Flying or Fairy by Aerilate / Pixilate. Sylveon's Hyper Voice gets Pixilate too. Mega Latias's Thunder Wave support skips its own types on purpose.
- **Reasonable alternate picks:** Zapdos, Volcanion, Lopunny, Kyurem-B, Diancie, Latios, Cresselia, Gardevoir, Aerodactyl, Whimsicott, Klefki, Absol, Celebi, Mamoswine, Donphan, Haxorus, Cobalion. Also Kyurem-B's Adamant Ice Beam and Bold Seismitoad and Gastrodon with Earthquake.
