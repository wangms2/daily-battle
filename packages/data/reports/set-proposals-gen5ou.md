# Gen 5 OU — proposed set changes

These come after the build fixes (whole-set picking, the Choice rule, natures that fit the spread). Gen 5's hand-added sets came from usage stats when the format was added, and most are real. So this gen has fewer drops than Gens 3 and 4.

## Drop

| Species   | Set                                                 | Why                                                                                            |
| --------- | --------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| Blissey   | Toxic attacker (padding), 5%                        | Weak; Blissey keeps its walls                                                                  |
| Jirachi   | Stealth Rock lead (Icy Wind / Thunder / U-turn), 5% | No STAB and a weak spread of moves                                                             |
| Dragonite | Substitute + Dragon Dance with Roost, 5%            | One attack                                                                                     |
| Victini   | All-out attacker (Charcoal), 5%                     | V-create from a Timid nature with 0 Attack EVs; the Choice Band and Choice Scarf sets cover it |
| Togekiss  | Nasty Plot (specially defensive)                    | Same four moves as the physically defensive set                                                |

## Fix moves

None. Roserade's Life Orb set keeps Rest: with Natural Cure, it wakes up cured when it switches out.

- **Choice Scarf Eruption Heatran:** Gen 5 Eruption Heatran must be Quiet.
